# Hemloc
Hemloc is a privacy-first messaging platform. It is fully decentralized, with no visible metadata. Hemloc users can communicate over a network with complete anonymity and privacy; nobody can read messages you send except the intended recipient, and nobody can tell who the intended recipient is or who sent the message. Any man in the middle cannot gain any information whatsoever on network activity, and even a full packet log can only tell who sent messages onto the network. This provides complete safety from any types of tracking or surveillance, protecting a user's identity and speech.
