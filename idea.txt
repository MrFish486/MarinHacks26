 - IDEA: secure messaging
    - decentralized
    - run app which starts web server with UI on localhost:whatever
    - 
 - Localhost webserver in PHP
 - Backend in Julia using RSA library
 - Use sockets
    - Keeps a certain port open, waits for incoming messages.
    - Looks for other machines on network with said open port and relays messages to them
 - Message format:
    - Checksum of part 3, unencrypted (message ID)
    - Checksum of part 3, encrypted (Recipient verification)
    - Part 3: Sender Handle + actual message, encrypted (Data)
 - Incoming messages have their Rv decrypted using the user's key
    - checksums are compared. If they match, message is saved in inbox
    - if they don't, message is instantly randomly relayed to one more computer and then discarded
 - Users have a handle (their public key)
    - Their private key is stored encrypted using AES with their password
    - To verify the password, the private key is unencrypted with it and then used to unencrypt a dummy text
    - private key format: private.key first 16 bytes are IV, the rest is the private key
